# To-Do List Application

A simple task management web app built with HTML, CSS and JavaScript. It was created as a practical exercise in web development, JavaScript DOM manipulation and GitHub version control.

## Features

- Add new tasks
- Mark tasks as completed (checkbox or green tick button)
- Delete tasks (red bin button)
- Filter by All / Pending / Completed, with live counts
- Tasks are saved in the browser using `localStorage`, so they survive a page refresh
- Responsive layout that works on desktop and mobile

## Technologies Used

- HTML5
- CSS3 (Flexbox)
- JavaScript (ES6, DOM manipulation, localStorage)

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/<your-username>/To-Do-List-Application.git
   ```
2. Open the folder and double-click `index.html` in any modern browser. No build step or server is needed.

## How to Use

1. Type a task into the input box and click **Add Task** (or press Enter).
2. Tick the checkbox or click the green tick to mark a task as completed.
3. Click the red bin icon to delete a task.
4. Use the **All**, **Pending** and **Completed** buttons to filter the list.
