# Password Strength Checker

A beginner-friendly password strength checker built with **HTML, CSS and JavaScript**. It checks a password locally in the browser and gives instant feedback.

## Features
- Checks minimum length (8 characters)
- Checks lowercase and uppercase letters
- Checks numbers and special characters
- Displays a strength level: Weak, Medium or Strong
- Includes a Show/Hide password control
- Responsive layout for mobile and desktop
- Password is not transmitted to a server

## Run the project
1. Download and extract the ZIP file.
2. Open the `password-strength-checker` folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. Type a password to see the checklist and strength meter update.

You can also use the VS Code **Live Server** extension: right-click `index.html` and select **Open with Live Server**.

## Project files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — password checks and strength calculation
- `screenshot.png` — preview of the implementation

## Important note
This is an educational indicator, not a guarantee that a password is secure. Do not enter a real password you currently use. A password manager can generate and store unique passwords for your accounts.
